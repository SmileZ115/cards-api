# cards-api

A TypeScript API for learning purposes

## About

A card management API that lets you list, create, update, and delete cards.
The idea was inspired by my other project, [Gwent](https://github.com/SmileZ115/gwent), and this is my first backend, built with Node.js, Express and TypeScript as a learning exercise.

## Features

- Create cards
- List those cards
- Look for a specific card by its ID
- Update a card
- Delete a card

## Built With

- [Node.js](https://nodejs.org/en)
- [express](https://expressjs.com/)
- [TypeScript](https://www.typescriptlang.org/)

## How to Run

1. Make sure you have Node.js `v22.18.0` or newer (running `.ts` files directly was introduced in `v22.6.0`, but only works by default, without an experimental flag, from `v22.18.0`)
2. Clone the repository and enter the folder:

```
git clone https://github.com/SmileZ115/cards-api.git
cd cards-api
```

3. Install the packages with `npm install`
4. Start the server with `npm run dev`
5. Access the server via `http://localhost:3000`

## Routes

| Method | Path | Description | Success | Errors |
|--------|------|-------------|---------|--------|
| GET | `/` | Welcome message | 200 | - |
| GET | `/cartas` | List all cards | 200 | - |
| GET | `/cartas/:id` | Get a card by its ID | 200 | 404 |
| POST | `/cartas` | Create a card | 201 | 400 |
| PUT | `/cartas/:id` | Update a card | 200 | 400, 404 |
| DELETE | `/cartas/:id` | Delete a card by its ID | 204 | 404 |

### Example

Creating a card:

```
curl -X POST http://localhost:3000/cartas -H "Content-Type: application/json" -d '{"name": "Geralt", "power": 15}'
```

The request body needs a non-empty `name` (text) and a `power` (number). The response is the created card, including the `id` generated by the server.

## Development

Node runs the TypeScript files but does not check the types. To check them, run:

```
npm run check
```
