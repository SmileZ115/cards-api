# cards-api

A JavaScript API for learning purposes

## About

A card management API that lets you list, create, and delete cards.
The idea was inspired by my other project, [Gwent](https://github.com/SmileZ115/gwent), and this is my first backend, built with Node.js and Express as a learning exercise.

## Features

- Create cards
- List those cards
- Look for a specific card by its ID
- Delete a card

## Built With

- [Node.js](https://nodejs.org/en)
- [express](https://expressjs.com/)

## How to Run

1. Clone this repository
2. Navigate to the folder
3. Install the packages with `npm install`
4. Start the server with `node index.js`
5. Access the server via `http://localhost:3000`

## Routes

| Method | Path | Description | Success | Errors |
|--------|------|-------------|---------|--------|
| GET | `/` | Welcome message | 200 | - |
| GET | `/cartas` | List all cards | 200 | - |
| GET | `/cartas/:id` | Get a card by its ID | 200 | 404 |
| POST | `/cartas` | Create a card | 201 | 400 |
| DELETE | `/cartas/:id` | Delete a card by its ID | 204 | 404 |

### Example

Creating a card:

```
curl -X POST http://localhost:3000/cartas -H "Content-Type: application/json" -d '{"name": "Geralt", "power": 15}'
```

The request body needs a non-empty `name` (text) and a `power` (number). The response is the created card, including the `id` generated by the server.
